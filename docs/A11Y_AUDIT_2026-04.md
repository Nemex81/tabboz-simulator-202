# Audit Accessibilità — Tabboz Simulator (Aprile 2026)

> Rapporto di analisi completo sulla fruibilità con screen reader (NVDA, JAWS, VoiceOver) per utenti non vedenti e ipovedenti. Copre coerenza semantica, efficacia degli annunci, impaginazione dei widget e gestione focus.

- **Data:** 22 aprile 2026
- **Stack:** React 19 + TypeScript 5.7 + Tailwind 4 + Radix primitives + sonner + recharts
- **Standard di riferimento:** WCAG 2.1 AA (AAA dove possibile), ARIA 1.2
- **Perimetro:** `index.html`, `src/App.tsx`, `src/main.tsx`, `src/components/**`, `src/hooks/**`, `src/index.css`, `src/main.css`

---

## 1. Panoramica generale

Stato qualitativo: **intermedio-alto**. Il lavoro aprile 2026 (sessione SR) ha chiuso quasi tutte le lacune su label pulsanti-icona, landmark `nav` dei menu principali, `hidden` sui TabsContent inattivi, heading `h2` nei tab, radiogroup in `SchoolBreakPanel`, close button localizzati. Restano lacune trasversali principalmente su **CSS globale (focus-visible, reduced-motion), grafici recharts, dipendenza dal colore, live region toast e skip link**.

Punteggio sintetico:

| Area | Stato |
| --- | --- |
| Label su controlli | OK ~90% |
| Landmark e heading | OK ~85% |
| Focus management programmatico (tab switch) | OK |
| CSS `:focus-visible` globale | **Assente** |
| `prefers-reduced-motion` | **Assente** |
| Live region toast sonner | Da verificare |
| Accessibilità grafici recharts | **Assente** |
| Dipendenza cromatica (voti, urgenze, salute) | Da mitigare |
| Skip-to-content | **Assente** |
| `lang` HTML | **Errato (`en` invece di `it`)** |

Criticità bloccanti:

1. `index.html` dichiara `lang="en"`: lo screen reader potrebbe scegliere la voce inglese per contenuti italiani.
2. Nessuna regola `:focus-visible` globale in `src/index.css` o `src/main.css`: dipendenza dallo stile per-componente, regressioni facili su primitive shadcn.
3. Grafici `recharts` (RadarChart, BarChart) privi di ruolo/etichetta: SR legge SVG muti.
4. Toaster sonner non configurato con `richColors` e `toastOptions` mirate: gli annunci esistono di default ma non sono garantiti in italiano e con livello di cortesia dichiarato.
5. Dipendenza dal colore per voti (verde/giallo/rosso) e urgenze esami (badge rosso "DOMANI!"): SR non percepisce la severità.
6. Assente skip-to-content: per raggiungere l'area giocabile lo SR deve scorrere header, time display, controlli giornalieri.

## 2. Audit per componente

### 2.1 `index.html`

- `lang="en"` ([index.html](../index.html)) non coerente con contenuti italiani.
- Manca landmark `<main>` esplicito già a livello shell (il `<main>` è atteso dentro `App.tsx`).
- Manca `<a href="#main-content" class="sr-only focus:not-sr-only">` come skip link.

### 2.2 `src/main.tsx`

- `<Toaster position="top-center" richColors />` senza `toastOptions` né `visibleToasts`/`duration` ragionati; sonner imposta `role="status"` di default ma non è ispezionato dal codice applicativo.
- `ErrorBoundary` non ha `role="alert"` sul fallback.

### 2.3 `src/ErrorFallback.tsx`

- Manca `<h1>` semantico nel fallback (`AlertTitle` è un div stilizzato).
- Testo misto inglese/italiano nel fallback di default.
- Nessun `autoFocus` sul bottone di ripristino.

### 2.4 `src/App.tsx`

- Non avvolge il contenuto con un `<main id="main-content" role="main">`.
- Le sezioni principali sono render fluenti senza landmark complementari (`aside`, `footer`).

### 2.5 `src/components/AppHeader.tsx`

- `<header>` + `<h1>` corretti.
- Bottone "Aiuto Tasti" senza `aria-label` esplicito sopra il `children` (se children è vuoto o solo icona).
- Simboli di genere/età (`♂`, `♀`) letti letteralmente: preferire `aria-label` testuale.
- Effetto `.neon-text-glow` può ridurre contrasto percepito.

### 2.6 `src/components/MainGameTabs.tsx`

- `<nav aria-label="Menu principale di gioco">` corretto.
- Focus transfer sul pannello attivo presente (`requestAnimationFrame`).
- Manca live region per annunciare testualmente il cambio tab (SR annuncia il trigger ma non una frase contestuale tipo "Scheda Città aperta").
- Heading `h2` di intestazione del menu non presente nel nav (solo trigger).

### 2.7 `src/components/CharacterSheet.tsx`

- `<section aria-labelledby>` + `h2` OK.
- Alcuni `TabsTrigger` hanno solo testo visibile + icona: aggiungere `aria-label` esplicito per robustezza (soprattutto nelle varianti mobile con solo emoji).

### 2.8 `src/components/StatsDashboard.tsx`

- **Bloccante:** RadarChart e BarChart `recharts` sono SVG muti. Mancano `role="img"`, `aria-label` sul container, `<figcaption>` testuale alternativa.
- Dipendenza dal tema per `stroke` primary: contrasto non garantito su tutte le varianti.

### 2.9 `src/components/TimeDisplay.tsx`

- `role="region"` + `aria-live="polite"` presenti su una parte limitata.
- Estendere `aria-live` all'intero region così cambi di fase/giorno sono annunciati senza evento utente.

### 2.10 `src/components/ActionButton.tsx`

- `aria-label` fallback OK.
- Focus ring `focus:ring-primary/50` dipende dal tema: contrasto non garantito; preferire `outline` fisso con `outline-offset`.
- `helpText` non legato via `aria-describedby`.

### 2.11 `src/components/ui/dialog.tsx` e `src/components/ui/sheet.tsx`

- Close button con `aria-label` italiano (fix aprile 2026).
- Radix fornisce focus trap + focus restore nativi: è necessario validare manualmente con NVDA che il focus torni al trigger e non si disperda.
- Nessun `aria-describedby` automatico quando manca `DialogDescription`.

### 2.12 `src/components/tabs/SchoolTab.tsx`, `CityTab.tsx`, `SocialTab.tsx`, `StatusTab.tsx`

- `SocialTab` e `SchoolTab` hanno `h2`. Verificare che `CityTab` e `StatusTab` abbiano intestazione `sr-only` equivalente.
- `StatusTab` raggruppa controlli di configurazione: serve `<section aria-labelledby>` o `role="group"` attorno ai toggle.

### 2.13 `src/components/GradeProgressPanel.tsx`

- Barre progressivo senza `role="progressbar"` + `aria-valuenow/min/max`.
- `gradeColor` (verde/giallo/arancio/rosso) unico indicatore: aggiungere etichetta testuale ("Eccellente/Sufficiente/Insufficiente").

### 2.14 `src/components/ExamsPanel.tsx`

- Badge "DOMANI!" rosso unica indicazione di urgenza: aggiungere `aria-label` o testo `sr-only` "Scadenza imminente".
- Lista esami: valutare `<ol>` con markup semantico o `role="list"` su gruppo.

### 2.15 `src/components/RelationshipsPanel.tsx`, `FriendshipsPanel.tsx`, `RelationCard.tsx`

- Heading OK.
- Card di relazione: garantire che azioni rapide (regalo, messaggio, rottura) abbiano `aria-label` completo "Azione X verso Y" anche quando il nome è in un parent.

### 2.16 `src/components/DiaryPanel.tsx`

- `section` + `h2` + `ul role="list"` OK. Mantenere questo come template di riferimento.

### 2.17 `src/components/HealthRecordPanel.tsx`

- `section aria-labelledby` + `h3` OK; proseguire con aggiunta di `role="progressbar"` per eventuali barre di HP.

### 2.18 `src/hooks/useKeyboardShortcuts.ts`

- Callback `announce()` invocata correttamente; verificare che il componente target dell'annuncio sia effettivamente una live region (`role="status"` o `role="alert"` con `aria-live`).

### 2.19 `src/index.css` / `src/main.css`

- Assenti: `:focus-visible`, `@media (prefers-reduced-motion: reduce)`, `prefers-contrast`, `::selection` accessibili.
- `sr-only` deve esistere (Tailwind la fornisce, ma serve `.focus\:not-sr-only` per lo skip-link).

## 3. Criticità trasversali

| ID | Tema | Impatto | Azione |
| --- | --- | --- | --- |
| T01 | `:focus-visible` globale mancante | Tastiera invisibile su primitive shadcn | Regole CSS globali |
| T02 | `prefers-reduced-motion` non gestita | Animazioni forzate | Media query globale |
| T03 | Sonner toaster senza configurazione SR verificata | Annunci toast inaffidabili | `toastOptions` + live region custom |
| T04 | Grafici recharts muti | SR non percepisce stats/voti | `role="img"` + `figcaption` |
| T05 | Colore come unico indicatore | Non-vedenti e ipovedenti perdono stato | Testo + simboli ASCII + `aria-label` |
| T06 | Skip-to-content assente | Navigazione ripetitiva | Link `sr-only focus:not-sr-only` |
| T07 | `lang="en"` | Voce sbagliata NVDA/JAWS | Cambiare attributo HTML |
| T08 | Live region cambio tab/fase | Cambio stato non annunciato | `<div role="status" aria-live="polite" className="sr-only">` dinamico |
| T09 | Barre progresso senza ARIA | Valori non letti | `role="progressbar"` |
| T10 | Dialog: focus restore non verificato | Focus perso alla chiusura | Test manuale + eventualmente `onCloseAutoFocus` |
| T11 | ErrorFallback non a11y | Errori non annunciati | `role="alert"` + `h1` |
| T12 | Responsive SR (320px, zoom 200%) non verificato | Focus ring e label sovrapposti | Test manuale + eventuali fix layout |

## 5. Raccomandazioni concrete (snippet di riferimento)

### 5.1 CSS globali

```css
/* src/index.css — append */
:focus-visible {
  outline: 3px solid hsl(var(--ring, var(--primary)));
  outline-offset: 2px;
  border-radius: 4px;
}

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

### 5.2 Live region globale

```tsx
// src/components/A11yLiveRegion.tsx
export function A11yLiveRegion() {
  return (
    <div
      id="a11y-live-region"
      role="status"
      aria-live="polite"
      aria-atomic="true"
      className="sr-only"
    />
  )
}
```

Abbinato a un helper `announce(msg: string)` che scrive `textContent` sul nodo.

### 5.3 Skip link e main landmark

```tsx
// src/App.tsx (pseudo)
<a href="#main-content" className="sr-only focus:not-sr-only focus:absolute focus:top-2 focus:left-2 focus:z-[9999] focus:p-2 focus:bg-primary focus:text-primary-foreground">
  Salta al contenuto principale
</a>
<main id="main-content" role="main">
  {/* ... */}
</main>
```

### 5.4 Grafici recharts

```tsx
<div role="img" aria-label={`Radar delle statistiche: ${stats.map(s => `${s.label} ${s.value}`).join(', ')}`}>
  <ResponsiveContainer>...</ResponsiveContainer>
  <p className="sr-only">Descrizione testuale dettagliata...</p>
</div>
```

### 5.5 Barre progresso voti

```tsx
<div
  role="progressbar"
  aria-valuenow={Math.round(grade * 10)}
  aria-valuemin={0}
  aria-valuemax={100}
  aria-label={`${subjectName}: ${grade.toFixed(1)} su 10 — ${gradeLabel(grade)}`}
>
  {/* ... */}
</div>
```

### 5.6 Toaster sonner

```tsx
<Toaster
  position="top-center"
  richColors
  closeButton
  toastOptions={{
    duration: 4500,
    classNames: {
      toast: 'group toast',
      description: 'group-[.toast]:text-muted-foreground',
    },
  }}
/>
```

### 5.7 ErrorFallback

```tsx
<div role="alert" aria-live="assertive" className="...">
  <h1>Errore imprevisto</h1>
  <p>...</p>
  <button autoFocus onClick={resetErrorBoundary}>Ricarica</button>
</div>
```
